# Heritage inbox

Add one line per node. The build turns each line into a node (candidate by default). Start a line with `!` to mark it confirmed, or `#` to switch it off. When a node later gets its own file in `heritage/`, the file wins.

Format: `Name | kind | year | parent | branch | why | url`

Kinds: person, work, idea, game, software. Branches: economics, cities, games, fiction, other.

```
# Hirschman, The Strategy of Economic Development | work | 1958 | Albert O. Hirschman | economics | Unbalanced growth as a method |
# Jacobs, Cities and the Wealth of Nations | work | 1984 | Jane Jacobs | cities | Import replacement and the local economy |
```
